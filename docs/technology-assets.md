# Technology marks

The project-card rail and stack panel serve these reviewed assets locally. Only symbols and short brand monograms are used, never artwork spelling the full caption. Every mark has one caption in the portfolio typeface and a reviewed optical size. The monochrome rail uses a centered 28px symbol chamber; the panel centers the same artwork in a 40px square chamber, matching the header and close control. Original proportions are retained. No runtime icon service is used.

The Simple Icons vectors above are unchanged. OpenAI and GitHub use the installed Remix Icon package.

The panel's colored symbols use the same local vectors as CSS masks. Colors come from the pinned collection's [brand metadata](https://github.com/simple-icons/simple-icons/blob/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/data/simple-icons.json); PHP, MySQL and Trigger.dev retain colors from their reviewed artwork below. Light mode mixes the source color toward black and dark mode toward white for contrast against the neutral chamber. Brands without a reviewed color remain monochrome. This changes the presentation, never the stored vector geometry. The rail stays monochrome in both themes.

## Cash Plus

`cash-plus.svg` contains the loop-arrow and perimeter paths from the [official Cash Plus logo](https://cdn.prod.website-files.com/6218cd1560a71e2f136765f7/6862e5d0d7cf29f11d80c43d_LOGO%20CASHPLUS.svg), linked by [cashplus.ma](https://www.cashplus.ma/). Their geometry is unchanged; the view box is cropped to the symbol. The wordmark, export scaffolding, lighting effects and embedded raster are omitted, reducing the 520,667-byte source to a 1,186-byte symbol. The panel uses the source's `#1F9097` teal; the rail is monochrome. Cash Plus retains ownership of the artwork; it is included only to identify the integration, without implying endorsement.
