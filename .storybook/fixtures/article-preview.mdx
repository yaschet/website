## Start With A Clear Question

### Keep The Reading Order Predictable

1. Introduce the constraint.
2. Explain the decision and its tradeoffs.
3. Show enough evidence for the reader to evaluate it.

> A short quotation should stay readable without competing with the heading above it.

## Make The Details Inspectable

The code block deliberately includes a long line so its horizontal scrolling can be reviewed on a narrow screen without widening the whole page.

```typescript
type Result = { ok: true; value: string } | { ok: false; reason: string };

export function describe(result: Result): string {
  return result.ok ? result.value : `The operation could not complete: ${result.reason}. Preserve the draft and offer a clear retry action.`;
}
```

| Review surface | What to check |
| --- | --- |
| Mobile | Reading width, wrapped headings and code overflow |
| Desktop | Line length, spacing and the article outline |
| Both themes | Text contrast, links and focus visibility |
