# Yaschet Portfolio

This workshop documents the portfolio's locally owned design foundations, reusable components and page compositions. Examples render the website's actual implementation with its production styles and fonts.

## Start with the product

- <a href="/?path=/story/foundation-overview--portfolio" target="_top">Brand overview</a> — typography, surfaces, actions and editorial composition together.

- <a href="/?path=/story/pages-casestudyarchitecture--in-context" target="_top">Case study page</a> — the diagram within the real page shell and an abridged Verto article.

## Find the right level

- **Foundation:** brand composition, color, typography, spacing and motion.
- **Components:** actions, feedback, fields, overlays, navigation, media and content.
- **Pages:** composed screens and route states.
- **Lab:** retained visual explorations without a current production consumer.

## Implementation status

Most component stories render components already used by the website. The case study diagram is the canonical local implementation, awaiting public MDX integration. Its page story is a review fixture; it does not replace the authored case study. Lab entries remain clearly separate from the active component catalog.

## Review behavior

Use the Theme toolbar to inspect light and dark materials. Component Controls expose supported variants where they are useful. Check narrow layouts, keyboard operation, visible focus and reduced motion as well as the default appearance.

Story interaction and accessibility checks run in both themes. Automated scans require manual follow-up for inconclusive results and do not establish complete accessibility. Contact examples use an isolated transport and never send email.

The code and verification commands are documented in `docs/storybook.md`. This workshop is a local review artifact; nothing here is published by opening it.
